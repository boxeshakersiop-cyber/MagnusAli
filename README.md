**MagnusAli ChessCOACH** — браузерный шахматный ассистент нового поколения для анализа позиций, изучения дебютов, тренировки тактики и визуального сопровождения партий на **Lichess.org** и **Chess.com**.

Версия **16.1** объединяет локальный **Stockfish 19**, быстрый JS-анализ, облачные позиции Lichess, семифигурные таблицы **Syzygy**, адаптивную силу до **4000 ELO**, естественный ритм ходов и полностью переработанный интерфейс **Apple Glass**.

## ✨ Что нового в v16.1

- Полностью новый **Apple Glass GUI** вместо старого неонового HUD.
- Новые профили: **Magnus Hunter**, **Coach** и **Human**.
- Диапазон силы расширен с `3000` до **4000 ELO**.
- Против соперника с рейтингом `3000+` максимальный расчёт включается автоматически.
- Stockfish 19 работает с `Hash 96 MB`, максимальным Skill Level и отключённым ограничением силы.
- В режиме 4000 программа ждёт завершения глубокого прохода перед выполнением хода.
- Добавлена безопасная попытка **детского мата** против соперников до `1200 ELO`.
- SDK получил новое имя `window.MagnusAliChessCOACH`; старый `window.CC` оставлен для совместимости.
- Конфиги переведены на формат `MAGNUSALI_CHESSCOACH_CONFIG_V16` с импортом старых конфигов v15.

## 🧠 Гибридный шахматный движок

### Фаза 1 — Fast Pass

Мгновенный локальный анализ позиции:

- генерация легальных ходов;
- проверка шаха и безопасности короля;
- поиск мата в один и два хода;
- обнаружение вилок, связок и висящих фигур;
- SEE-анализ разменов;
- контроль повторений и патовых позиций;
- оценка пешечной структуры и проходных пешек;
- подготовка тепловой карты доски.

### Фаза 2 — Deep Pass

Углублённый параллельный расчёт:

- локальный **Stockfish 19 WASM** в отдельном WebWorker;
- таблица транспозиций и эвристика killer moves в JS-ядре;
- Lichess Cloud Evaluation;
- база дебютных партий Lichess Explorer;
- MultiPV для анализа нескольких равноценных линий;
- повышенный бюджет расчёта для угроз королю;
- автоматическое обновление рекомендации при нахождении более сильного хода.

### 🔮 Syzygy

При семи фигурах или меньше подключаются таблицы эндшпилей:

- точный результат `Win / Draw / Loss`;
- показатели `DTZ` и `DTM`;
- выбор кратчайшего корректного пути к победе;
- защита от случайного перехода в ничейную позицию.

> **Примечание:** значение `4000 ELO` обозначает максимальный профиль настроек движка. Фактическая сила зависит от процессора, доступного времени, позиции и выбранного контроля.

## 🎯 Адаптация под рейтинг соперника

ChessCOACH считывает отображаемый рейтинг соперника из интерфейса площадки и выбирает подходящий профиль расчёта:

| Рейтинг соперника | Профиль |
|---:|---|
| до 1200 | Начинающий + радар быстрого мата |
| 1201–1800 | Клубный игрок |
| 1801–2400 | Эксперт |
| 2401–2999 | Мастер |
| 3000+ | Super-GM + автоматический режим 4000 |

Если рейтинг недоступен, используется сила, выбранная пользователем на ползунке.

## 👑 Безопасная попытка детского мата

Против соперника до `1200 ELO` за белых программа может попробовать линию:

```text
1. e4
2. Bc4
3. Qh5
4. Qxf7#
```

Линия не выполняется вслепую. Каждый кандидат проверяется Stockfish:

1. ход должен находиться среди `12` линий MultiPV;
2. потеря оценки не должна превышать `0.70` пешки;
3. позиция не должна содержать немедленную угрозу нашему королю;
4. `Qxf7#` получает приоритет только при подтверждённом форсированном мате;
5. при корректной защите соперника план отменяется и выбирается обычная сильнейшая линия.

## 📜 MagnusAli Scripting SDK v2.0

SDK позволяет подключать пользовательские JavaScript-модули из папки `scripts/`.

Основной глобальный объект:

```javascript
window.MagnusAliChessCOACH
```

Совместимый алиас:

```javascript
window.CC
```

Пример регистрации:

```javascript
(function () {
  const sdk = window.MagnusAliChessCOACH || window.CC;
  if (!sdk) return;

  sdk.registerScript({
    id: "my_script",
    name: "Мой скрипт",
    version: "1.0.0",
    author: "MagnusAli Community",

    onEnable(api) {
      api.osd.showBanner({
        id: "hello",
        text: "Скрипт включён",
        accentColor: "#0a84ff",
        position: "top-center"
      });
    }
  });
})();
```

SDK предоставляет:

- независимые перетаскиваемые окна;
- вкладки, кнопки, тумблеры и слайдеры;
- ColorPicker, FilePicker и Keybind;
- OSD-баннеры;
- WebAudio-сигналы;
- CSS-инъекции;
- доступ к состоянию партии;
- 60 FPS Canvas поверх доски;
- хуки `onEnable`, `onDisable`, `onTick`, `onMove`, `onEvalUpdate` и `onFrame`.

Полная документация: [`MAGNUSALI_CHESSCOACH_API.md`](MagnusAli-ChessCOACH/MAGNUSALI_CHESSCOACH_API.md).

## 🚀 Установка

1. Скачайте и распакуйте проект.
2. Откройте страницу расширений:
   - Chrome / Brave: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Яндекс.Браузер: `browser://extensions/`
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `MagnusAli-ChessCOACH`, в которой находится `manifest.json`.
6. Откройте Lichess или Chess.com.

После обновления исходников нажмите кнопку **Обновить** на карточке расширения и перезагрузите шахматную страницу.
